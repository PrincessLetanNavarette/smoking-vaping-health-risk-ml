# Smoking & Vaping Health Risk Classifier (BRFSS 2020)

Name: Princess Loureen Letan Navarette   

## Project Description
This project implements an entry-level machine learning classification system
that predicts overall health risk associated with cigarette smoking and vaping
using CDC BRFSS 2020 public health survey data.

## Features
- Age group
- Sex
- Weight category (BMI)
- Cigarette smoking behaviour
- Vaping behaviour
- Diabetes / Prediabetes

## Model
- Algorithm: Logistic Regression
- Task: Binary Classification (High Risk vs Low Risk)
- Metrics: Accuracy, Precision, Recall, F1-score, ROC-AUC

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the notebook:
   notebook/smoking-risk-a2.ipynb

3. Run the app:
   python app/app.py
